# Analysis tools

Magnolia's analysis tools allow you to explore your coded data from different angles: how often codes appear and where, which codes go together, what your participants say about each code, and which words they use. Their results are interactive. Click a cell, a bar or a word and Magnolia shows you the passages behind it in the Query Results pane.

**To open an analysis tool:**

1. Click the `Analyse` tab in the ribbon.

2. Click the tool you want.

The tool opens as a tab in the Viewer.

## Choosing a tool

The tools are grouped by what they work with.

### Codes

| Tool | Use it to… |
| --- | --- |
| [Codes in Documents](/guide/codesindocuments) | Count how often each code appears in each document or group of documents. |
| [Framework Matrix](/guide/frameworkmatrix) | Write a summary of what each code looks like in each document. |
| [Code Co-Occurrences](/guide/codecooccurrences) | See which codes overlap with each other. |
| [Code Orders](/guide/codeorders) | See the order in which codes appear in each document. |
| [Code Frequencies](/guide/codefrequencies) | See how much of each document is covered by each code. |

### Queries

| Tool | Use it to… |
| --- | --- |
| [Results in Documents](/guide/resultsindocuments) | Count how many results your saved queries find in each document. |

### Words

| Tool | Use it to… |
| --- | --- |
| [Word Frequencies](/guide/wordfrequencies) | See which words appear most often, as a list, a bar chart or a word cloud. |
| [Word Combinations](/guide/wordcombinations) | See which words go together: the phrases that repeat, the words that appear alongside a word you choose, and every context a word appears in. |

### Bringing it together

| Tool | Use it to… |
| --- | --- |
| [Relationships](/guide/relationships) | Map how codes, documents, memos and other things in your project relate to each other. |
| [Reports](/guide/reports) | Compile documents, query results, quotes, memos and analyses into a single PDF. |

## What the tools have in common

Most tools share the same building blocks, so once you have learnt one, the others work the same way:
- `From these documents` chooses which documents the tool looks at. See [Selecting documents](/guide/documentselector);
- `Grouped by` combines documents into groups, such as the participants' student type. See [Grouping](/guide/grouping); and,
- `Results` shows what the tool found. Most tools can show their results in more than one way, for example as a table or as a chart.

## Saving and exporting

Click `Save Analysis` to keep an analysis. It appears in the Saved Analyses Panel, from where you can open it again, attach a memo to it, or drag it into a [Report](/guide/reports).

Most tools can also export their results by clicking `Export CSV`, which you can open in a spreadsheet.
